# 纯钧产品与当前边界

纯钧是神兵系列的本地桌面图片工具，面向需要压缩、转换、裁剪，以及处理明水印和 AIGC 元数据声明的用户。Windows 11 优先，简体中文，主画板 1440×960、最小窗口 1120×760。窗口按逻辑像素创建，高 DPI 屏幕上会被放大（200% 缩放时 1440×960 就是整块屏幕），因此启动时按显示器工作区判断：放不下就先钳到工作区再最大化，避免底部操作条被任务栏裁掉；放得下的屏幕保持设计尺寸。标题栏的最大化/还原按钮跟随真实窗口状态。

当前桌面程序可以完成本地导入、压缩、转换、裁剪、明水印、元数据声明和副本导出。自动 OCR、复杂修补、HEIC 解码和 AVIF 解码没有接入；这些入口会说明不支持，不会显示识别就绪。导出使用原图目录下的纯钧导出子目录，或用户选定的单一文件夹，不保留源目录的层级结构。导出与预览按「全局参数 + 逐图字段」组合执行：裁剪、旋转/翻转、水印与声明编辑属于具体图片、随该图草稿走，画质/目标体积/缩放/输出格式等跟随当前工作区；任何工作区里点导出处理的都是整个文件列表——在裁剪工作区“应用全部”后“应用并继续”即批量导出，每张按各自原始尺寸换算裁剪。导出时单张失败只标记该项；处理中按解码、量化、压缩、写入、回读等阶段回传进度，完成后结果列表带缩略图，可预览、复制或定位副本。厂商列表仍是适配目标。

2026-11-04 导出流程按用户确认精简：普通导出直接进入进度，不再经过独立检查页。底栏显示保存位置并可直接选择原生目录，“导出设置”就地展开本次格式、前后缀、重名策略和导出后打开文件夹。当前命名修改不自动写成默认偏好；默认命名在设置页修改，输出目录仍仅当前会话授权。透明背景转 JPEG、动画/多页提取、声明修改、以及目标格式无法承载的元数据差异才弹窗确认；后者逐项列出将丢弃的字段，确认丢弃或改用可承载格式，不能静默绕过。预检使用现有证据字段，最终仍由 Rust 防护拒绝未确认的不安全操作。

Figma 展开示例为 [11:1250](https://www.figma.com/design/A1vGeie8es1ZWYTU8dJnIQ?node-id=11-1250)，风险状态为 `50:959`、`50:1251`、`50:1465`；节点记录在 `design/export-flow-revision.json`。旧本地设计 HTML/“导出检查”PNG 是历史版本，该流程以本次修订与 Figma 为准。

界面文案按用户截图统一精简：常驻区域只保留操作名称、参数、字段结果与必要状态，移除重复宣传、技术实现说明和无效更新入口。真实错误与操作风险按场景反馈；未安装的识别能力只显示简短状态，未读取图片时不显示检测结论。默认命名与本次参数仍分开，位置授权范围直接写在字段名中。Figma 19 个高保真画板同步清理，记录见 `design/copy-cleanup-revision.json`；其余未完成功能仍以本文件和问题登记为准。

侧栏不再重复展示系列名和产品名，工具入口直接置顶。滚动区域统一使用无箭头、零占位的 4px 悬浮滑块，仅在溢出时出现，并保留滚轮、拖动和键盘操作。适应画布不滚动，100% 大图支持双向滚动。Figma 最小窗口样式为 [63:772](https://www.figma.com/design/A1vGeie8es1ZWYTU8dJnIQ?node-id=63-772)，记录见 `design/scrollbar-revision.json`。

压缩口径：JPEG、AVIF 按画质有损编码；PNG 默认转为 8 位调色板（有损，按画质降色到 32–256 色，保留透明），关掉开关才是无损重编码——无损重编码对已经优化过的 PNG 几乎不改变体积；WebP 这一版只有无损编码，画质滑杆对它无效。按体积压缩时，PNG 只能靠降低画质逼近目标，达不到就如实标注未达标，不会偷偷缩小画面。

2026-11-04 审查状态见[问题与需求登记](../reviews/2026-11-04.md)。元数据页通过原容器直写，避免重新编码像素；JPEG/PNG 的未知 XMP 改写会拒绝。重编码为 JPEG/PNG 时，源文件的 EXIF（含未知厂商标签）、ICC、XMP 与 PNG 文本/色彩块逐字节迁入副本并复检、回读，EXIF 方向烘焙旋正后归一写入；迁移以合成真实容器文件逐字段验证，真实设备/平台样本验收仍待。WebP/AVIF 目标不承载这些字段，导出前逐项确认丢弃或改格式；C2PA 字节线索不随重编码保留并明示凭证失效。BMP/TIFF/GIF/SVG 源同样迁移：TIFF 把首页 IFD0 整块搬进副本（元数据与像素交错、结构损坏或 BigTIFF 时逐项确认丢弃），GIF/SVG 提取 XMP，BMP 迁移 V5 内嵌 ICC、外链配置列明不可承载；JPEG 源超过单段的 XMP 扩展包（ExtendedXMP）按 MD5 重组整包迁移，重组失败上报不静默。转 sRGB 未接。APNG 暂不处理。多页 TIFF 可选择导出指定页（越界明确报错）；选第 2 页及以后时，记录在第 1 页的 EXIF/ICC 会逐项列出并要求确认丢弃，文档级 XMP 仍迁移。TIFF 元数据与像素交错时（常见编码器布局）按字段值逐字节重排迁移，不夹带像素字节；含 MakerNote 的交错文件保守要求确认。JPEG/PNG/WebP 预览取编码后像素；AVIF 预览仅为编码前画面，字节回读不代表解码验证。默认输出目录只在当前会话有效，自选位置没有跨启动持久化。拖放到窗口的文件夹会就地展开为图片（按设置决定是否含子文件夹，当前导出目录排除，展开失败的项显示为失败记录）；会话内最多保留 200 张导入。导出读取源文件前会复查文件与父目录是否被换成链接或装载点，发现即拒绝。任务进度只升不降，取消后结束消息和报告会写明未执行的数量，失败与未达标项可按当时的原参数重试；来源报告写失败会在结束消息中明示。本机设置/草稿/历史以原子替换写入，解析失败的旧文件会留档（`.corrupt-` 前缀）而不是被覆盖，剪贴板磁盘缓存只保留最近 20 份。自选的输出目录会记住并在下次启动恢复（目录仍在且不是链接时生效；这是应用内的记录，不是系统对话框重新授权）；默认目录（原目录/纯钧导出）的导出同样记入本机历史，"打开文件夹"对两种位置都可用。设置页可保存/恢复工作区草稿：文件列表与当时的参数一起还原；撤销支持重做（Ctrl+Shift+Z / Ctrl+Y）。关闭“保留本机处理记录”后不再保存新记录、历史页显示已关闭说明，已保存的记录不会被删，重新打开开关即恢复显示。预览生成期间参数被改动时，过期结果会被丢弃并提示重新生成。帧提取逐帧惰性解码并受累计像素预算约束，缩放输出不超过 4000 万像素，超大剪贴板图片按像素与字节数拒绝。写入副本优先硬链接独占创建，不支持硬链接的卷回退为独占创建写入，同样不覆盖已存在文件。

## 已确定的产品要求

| 领域         | 后续应实现的能力                                                                    |
| ------------ | ----------------------------------------------------------------------------------- |
| 文件与工作区 | 文件/文件夹/拖放/剪贴板，真实格式、批量列表、共享草稿、预览对比、撤销与恢复         |
| 压缩         | 质量预设、目标体积、质量下限、真实字节结果、不更大策略、色彩和来源保留              |
| 转换         | JPEG/PNG/WebP/AVIF 等矩阵；透明度、动画、多页、方向与 ICC/HDR 明确处理              |
| 裁剪         | 自由/固定比例、精确尺寸、旋转、撤销及批量应用                                       |
| 明水印       | 用途/证件/版权/品牌/AIGC，文本/图片、斜向平铺、透明度、间距、日期、检测、删除和改写 |
| 元数据       | 自动读取来源及声明，一键保留/补充/替换/删除，支持容器导出后回读；不依赖 OCR         |
| 桌面与导出   | 原图只读、副本输出、重名不覆盖、进度/取消/失败重试、本机历史及缓存管理              |

无账号、上传、云推理、后台遥测、默认联网更新或训练数据收集。核心运行离线；基础 OCR 随包按需加载，增强模型按需安装并支持本地导入。包装策略已确定，具体引擎、模型、体积、精度与运行库仍需实测。

明水印直接绘制到图片，包括身份证复印件“仅供办理〔事项〕使用，他用无效”；文字绘制无需 AI。OCR 输出文字/位置/置信度供复核，不把所有识别文字当作水印；复杂区域修补独立为可选本地能力。

元数据主流程自动识别，不要求用户手填厂商、编码和原始内容编号。缺失时显示未提供/来源无法确认。补写时可以选择内置平台清单（即梦/豆包、通义万相/千问、混元、文心、可灵/可图、ChatGPT、Gemini、Adobe Firefly、Midjourney）或手动填写声明主体：名称按用户声明写进 ContentProducer / ContentPropagator，编号一律由纯钧生成 chunjun 前缀，不写入厂商原始编号、不伪造厂商凭证，界面与结果里都会说明名称未经核验。主流目标包括即梦/豆包、通义万相/千问、混元、文心、可灵/可图、ChatGPT、Gemini、Adobe Firefly、Midjourney；按产品、原始下载入口和格式取样验收后才标记支持。

C2PA 字段、签名、本地信任、离线未验证项分开；未检出不等于非 AI。普通 Software/CreatorTool 是辅助证据，不是 AI 鉴定。像素隐形水印与元数据不是同一机制，不承诺 SynthID 通用检测/删除或原厂凭证伪造。

## 视觉与验收目标

保留“叠帧·方寸”Logo、48 枚功能图标与 8 类文件图标。暖白 `#F7F7F3`、石墨 `#252E29`、青绿 `#276650`；细线、中文排版、明确焦点与文字反馈，不增加 AI 聊天气泡、大渐变或吉祥物。内置 Noto Sans SC 可变字体（100–900，SIL OFL 1.1，许可全文随包），不再依赖系统字体回退。

完整 UI 使用约 176px 导航、223px 文件栏、弹性预览、344px 设置栏和固定底部操作。空列表、压缩、转换、裁剪、声明、明水印、处理中和设置按 Figma 画面排布。示例照片和未安装的识别结果不会被画进界面。

无遥测。导出以最终字节和回读为准。100 张批量、OCR、平台原始样本和清洁机器断网安装仍未验收。
