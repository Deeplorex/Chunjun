# 纯钧 · 功能清单

神兵系列中的一把。本文件是压缩、转换、裁剪三个模式的产品决策，后续实现按此建造，不再另起炉灶。本阶段不接入编码器。界面原型：`design/prototype/index.html`。

口号只用一句，放在字标下：去冗留华。按钮与状态用白话：压缩、转换、裁剪、排队、处理中、完成、失败。

## 1. 产品范围

一个工作室，三种模式。文件列表在模式之间共享。一次「开始处理」只执行当前模式。

输入（扩展名不区分大小写，`.jfif` 视作 JPEG）：

JPG、JPEG、PNG、WebP、GIF、SVG、AVIF、JXL、HEIC、HEIF。

输出：

| 模式 | 可写出的格式 |
| --- | --- |
| 压缩 | 与输入相同。JXL、HEIC、HEIF 不能压回原格式 |
| 转换 | JPG、PNG、WebP、AVIF、GIF |
| 裁剪 | 默认 PNG。可选沿用原格式，规则见第 6 节 |

JXL、HEIC、HEIF 只作为输入解码。不提供这三种格式的编码。

处理全部在浏览器内完成。图片、缩略图、成品字节都不上传。无账号，无水印，无配额。设备内存是唯一上限。首次需要网络载入字体与 WASM；载入成功后可离线使用。离线首次打开时，工作室仍可打开，开始处理时提示：需要先在有网络时载入一次编码器。

## 2. 信息架构

无营销页、无博客、无更新日志、无语言切换、无独立缩放工作室。

```
工作室
├─ 顶栏：字标「纯钧」/ 短句「去冗留华」/ 模式 / 「本地」
├─ 舞台：空状态的置入区，或当前文件的预览
├─ 铭文栏：当前模式的参数与开始、下载
└─ 队列：全部已置入文件
```

模式切换：顶栏三个文字按钮，键盘 `1` `2` `3`。当前模式有一条 1px 银线，从左向右画出。切换模式不丢弃文件。尚未完成的项回到「排队」。已经生成的成品留在该项的成品记录里，可继续下载。

桌面优先，宽度从 1280 起完整展开。窄宽度以 880 为设计宽度：铭文栏移到舞台下方，队列改为横向滚动，模式改为三等分。再窄到 720 仍保持同一结构，不另做一套手机信息架构。

## 3. 共享行为

### 3.1 置入

三种入口等价，都追加到队列末尾，不按文件名重排：

- 拖入文件或文件夹。文件夹递归读取子目录。
- 「选择图片」多选。
- 「选择文件夹」。
- 粘贴。剪贴板里的图片成为新项，文件名为 `粘贴-HHmmss`，扩展名按 MIME。无图片则忽略，不提示。

非图片记入一次轻提示：`已忽略 N 个非图片`，约 4 秒后消失。不进入队列。

同一文件可以置入两次。导出重名时加 `-2`、`-3`，规则见第 9 节。

空队列时舞台是置入区，铭文栏与队列不占位。第一张图进入后，舞台、铭文栏、队列以刃线拉开。清空最后一张则回到置入区。

原型中的「查看样张」只为走通界面，样张由本地画布生成。正式产品没有这个入口。

### 3.2 队列与选择

每项显示：缩略图、文件名、像素尺寸、原体积、状态、成品名与体积（完成后）。

状态只有四种：排队、处理中、完成、失败。

另有选择态「不处理」：该项的勾选取消。它不进入本次处理，不算失败，不进压缩包。默认全部勾选。

操作：

- 单击一项，舞台改看它。
- 勾选控制是否参与本次处理。
- 「移除」删除该项。若正在处理，先中止该项，再移除。
- 「清除已完成」只移除状态为完成的项。
- 「清空」：没有已完成项时立即清空并回到置入区。有已完成项时，按钮先变成「确认清空」，再点一次才执行。处理中途清空会先停止。

同时只处理一张，按队列从上到下。避免两张大图同时解码。

「开始处理」只跑勾选且状态为排队或失败的项。已完成的不自动重跑。失败项可以「重试」，重试把该项放回本次运行。

「停止」：当前这张中止，状态为失败，原因 `已取消`；不再开始后面的项；已完成的保留；尚未开始的保持排队。

参数是工作室级的，按格式分别记住，作用到所有排队项：

- 压缩、转换：改质量或格式，立即影响所有仍在排队、且格式匹配的项。
- 裁剪：比例、用途、摆正是模板。每张图有自己的选区，初始为居中的最大选区。用户拖过某张的选区后，该张标记为已单独调整，之后改全局比例不再覆盖它，直到点「重置选区」。

舞台在没有当前文件时，开始、下载为禁用。

### 3.3 预览与成品

滑杆驱动的是预览，最长边 1280，防抖 120ms。预览旁标「预览」。

「开始处理」对原图像素做全尺寸编码。完成后对照标成「成品」。成品字节以编码器实际输出为准。

预览体积用下面的曲线估算，只用于滑杆反馈，实现时不得拿它当成品字节：

- JPEG、WebP：`原字节 × (0.05 + 0.57 × (质量/100)^1.4) × 像素比`
- AVIF：上式 JPEG 估算 × 0.55
- PNG：`原字节 × (1 - 0.04 × 优化等级)`，等级 0–6
- GIF：`原字节 × (1 - 0.08 × 优化等级) × (1 - 有损/200)`
- SVG：不估算，文案为「以 SVGO 结果为准」

像素比 = 输出像素数 / 原图像素数。不缩放时为 1。

### 3.4 元数据

压缩与转换都有「去除元数据」，默认开启。

开启：先按 EXIF 方向把像素转正，再去掉全部元数据，方向标签写成 1。

关闭：仍先转正像素。保留 ICC、版权、作者。地理位置一律删除，包括 GPS IFD 与 XMP 中的位置。界面在开关旁始终写明：`地理位置始终剔除。关闭后保留方向、色彩与版权。`

裁剪不复制元数据。裁剪成品只有像素。

### 3.5 下载

单项「下载此张」在该项完成后可用。

「打包下载」把所有状态为完成的成品打成一个 ZIP。压缩方式用 STORE，不再压一次。失败项不进入包。若有失败，提示 `失败项不进入压缩包`。没有完成项时按钮禁用。

浏览器只负责下载。没有「覆盖原文件」。铭文栏常驻：`原文件不会被改写`。

### 3.6 缩放与对照

缩放作用于舞台，默认「适应」。

- 适应：整图落入舞台。
- 100%：1 个原图像素对 1 个屏幕像素。
- 200%：2 倍。
- 滚轮以指针为中心，范围 25%–400%。
- 双击画面（不在刃线、不在裁剪手柄上）在「适应」与 100% 之间切换。
- `+` `-` 以 10% 步进，`0` 回到适应。

压缩与转换使用前后对照。左侧原图，右侧预览或成品。分界是一根竖向银线，可拖。左键与右键不使分界跳跃，避免误触。双击银线回到 50%。方向键移动 2%，按住 Shift 移动 10%。按住 `H` 暂时看全幅原图，松开恢复。

裁剪不用这条分界。选区外压暗，即是裁之前的上下文。完成后可在「选区 / 成品」之间切换。

### 3.7 键盘

焦点在输入框、滑杆里时，单键快捷键不触发。

| 按键 | 作用 |
| --- | --- |
| `1` `2` `3` | 压缩、转换、裁剪 |
| `Ctrl` 或 `⌘` + `O` | 选择图片 |
| `Ctrl` 或 `⌘` + `Shift` + `O` | 选择文件夹 |
| `Ctrl` 或 `⌘` + `V` | 粘贴 |
| `Ctrl` 或 `⌘` + `Enter` | 开始处理 |
| `Esc` | 停止处理；若没有在处理，取消当前拖拽 |
| `Delete` 或 `Backspace` | 移除当前项 |
| `H`（按住） | 看全幅原图 |
| `←` `→` | 移动对照分界 2% |
| `Shift` + `←` `→` | 移动对照分界 10% |
| 方向键 | 裁剪模式下，选区移动 1 个原图像素 |
| `Shift` + 方向键 | 选区移动 10 像素 |
| `Shift`（拖角时按住） | 自由比例下临时锁定当前比例 |
| `+` `-` | 缩放 ±10% |
| `0` | 适应 |
| `?` | 打开或关闭快捷键层 |

### 3.8 内存、离线、取消

不设人为的文件大小上限，也不设「超过多少像素就拒绝」。

软提示，不拦截：

- 长边 ≥ 8000，或文件 ≥ 40MB：`大图，处理时会占用较多内存`
- 解码体积 `宽 × 高 × 4` ≥ 256MB：`解码后约占 N MB 内存`（N 向上取整到 MB）

浏览器抛出内存错误时，该项失败，原因 `内存不足`。其余项继续。

WASM 放在模块 Worker 里。不依赖 SharedArrayBuffer，因此不要求 COOP/COEP。主线程只留界面、队列和预览位图。原图缓冲在该项移除或清空时释放。

预览与正式编码都可中止。停止后已写出的成品保留，未写完的缓冲丢弃。

## 4. 压缩

压缩去掉冗余字节。默认不改变像素尺寸，不改变格式。

### 4.1 按格式的控件

当前文件是什么格式，铭文栏就展开什么控件。队列里还有别的格式时，加一句：`队列里有多种格式。参数按格式分别记住，作用在所有排队项上。`

| 格式 | 控件 | 默认 | 编码器（界面以小字注明，不作为品牌） |
| --- | --- | --- | --- |
| JPEG | 质量 1–100 | 85 | MozJPEG |
| WebP | 质量 1–100 | 80 | libwebp |
| AVIF | 质量 1–100 | 50 | libavif |
| PNG | 优化等级 0–6 | 2 | OxiPNG |
| GIF | 优化等级 1–3，有损 0–100 | 等级 2，有损 0 | gifsicle |
| SVG | 无滑杆 | SVGO 默认多遍 | svgo |

文案：

- JPEG：`从 85 起。压缩不改变像素尺寸。`
- AVIF：`AVIF 的 50 约相当于 JPEG 的 85。`
- PNG：`无损。只去掉冗余，不改画面。`
- GIF 有损为 0：`不损伤颜色。`
- SVG：`只去掉冗余，不栅格化。`

切换当前文件会切换滑杆，不把 JPEG 的 85 写进 PNG。用户改过的值按格式记住，直到清空队列。

质量或等级只影响同格式的排队项。已完成项不跟着变。

GIF 压缩保留全部帧。

### 4.2 按质量 / 按体积

分段控制，默认「按质量」。

「按体积」只对 JPEG、WebP、AVIF、GIF 有意义。当前文件若是 PNG 或 SVG，目标体积区仍然可见，但说明：

- PNG：`无损格式难以压到目标。若要达标，请改用转换，输出 JPG 或 WebP。`
- SVG：`SVG 只做结构精简，不保证体积。`

不自动改格式。

按体积的预设：100KB、200KB、500KB、1MB、2MB、自定义。默认选中 200KB。自定义为整数 KB，范围 1–20480。非法输入不启动该项，原因 `目标体积无效`。

按体积的算法，实现时用真实编码字节做二分，最多 12 次：

1. 在当前像素尺寸上，于「最低质量」与 100 之间二分。质量步长为 1。
2. 找到能放进目标的最高质量即停止，并采用它。
3. 若最低质量仍超出目标：
   - 「允许缩小」关闭：以最低质量出图，状态仍为完成，附注 `仍大于目标`。
   - 「允许缩小」开启（默认开启）：长边反复乘 0.9 并取整，每一步重新二分。长边下限 320。某一步放进目标即采用该尺寸与质量。缩到下限仍放不进：以最低质量与该尺寸出图，状态为完成，附注 `仍大于目标`。

最低质量默认 40，范围 1–90。它只在按体积时出现。

缩小发生时，预览与完成附注写明：`长边缩至 W`。文件名仍带目标体积，见第 9 节。

按体积不提供单独的质量滑杆。铭文栏显示预计落点，例如 `预计质量 40，长边缩至 1774`。正式跑完后改成实际质量与实际尺寸。

### 4.3 JXL / HEIC / HEIF

这三项可以出现在队列里并解码预览（HEIC 见第 7 节）。在压缩模式下开始处理时，该项失败，原因：`暂不能压回原格式，请改用转换`。铭文栏提供「改用转换」，切到转换并把输出设为 JPG。

## 5. 转换

把画面收成更合适的格式。默认输出 WebP，质量 80。

输出五选一：JPG、PNG、WebP、AVIF、GIF。切换输出格式时，质量回到该格式的默认值（JPG 85、WebP 80、AVIF 50、GIF 有损 0、GIF 等级 2）。PNG 没有质量滑杆。

SVG 作为输入时，增加「栅格宽度」，默认 `min(viewBox 宽度 × 2, 4096)`；没有 viewBox 时默认 1600。高度按比例。最长边不超过 4096。

### 5.1 透明

| 输出 | 透明 |
| --- | --- |
| JPG | 不保留。必须铺底 |
| PNG、WebP、AVIF | 保留半透明 |
| GIF | 保留 1 位透明。alpha ≥ 128 为不透明，其余为透明。不铺底 |

JPG 的底色两选一，默认墨色 `#080A0C`，另一项白色 `#FFFFFF`。不提供取色器。

源图有透明、且输出为 JPG 时，舞台横条：`透明将消失。转为 JPG 时以墨色填入。` 底色改白色则改成「以白色填入」。用户不确认也能开始，横条一直留着。

### 5.2 动画

| 情况 | 行为 |
| --- | --- |
| 源为静图 | 无动画控件 |
| 输出 GIF | 保留全部帧 |
| 输出 WebP | 「保留动画」默认开 |
| 输出 AVIF | 「保留动画」默认关。旁注：`动图 AVIF 兼容不稳定，默认只取首帧。` |
| 输出 JPG、PNG | 只取首帧。横条：`将只保留首帧` |

压缩模式不出现这些横条，因为压缩不改格式，GIF 帧数保留。

## 6. 裁剪

裁剪是一刀，不是另一间缩放工作室。选区即刀口。输出默认是选区的像素，不二次压缩。

### 6.1 比例

自由、1:1、4:5、3:4、3:2、4:3、16:9、9:16、1.91:1。默认自由。

点选一个比例：若该张尚未单独调整，选区改为图内居中的最大矩形。已单独调整的图不跟着变。

拖动手柄：

- 八个手柄：四角与四边。
- 自由比例下，拖边只改一个方向；拖角自由缩放。
- 锁定比例时，拖角保持比例，拖边则另一边联动，对边为锚点。
- 自由比例下按住 Shift 再拖角，临时锁定拖动开始时的比例。
- 在压暗区域拖拽，可拉出新选区。锁定比例时新选区服从该比例。
- 选区限制在画面内。最小 32×32 原图像素。
- 方向键移动选区，不改变大小。移到边缘即停。

### 6.2 用途

用途只是比例加上建议像素帧，用白话，不另做一套工具。

| 名称 | 比例 | 建议帧 |
| --- | --- | --- |
| Instagram 帖子 | 1:1 | 1080×1080 |
| Instagram 竖图 | 4:5 | 1080×1350 |
| Instagram 故事 | 9:16 | 1080×1920 |
| YouTube 封面 | 16:9 | 1280×720 |
| 小红书 | 3:4 | 1080×1440 |

点用途等于点对应比例，并填入建议帧。比例行同步亮起。

### 6.3 像素帧

宽、高两个整数输入。默认等于选区的原图像素，旁注 `默认即选区像素，不放大。`

- 锁定比例时，改一边，另一边按比例取整。
- 输入大于选区：钳制到选区像素，提示 `已限制在原图像素内`。
- 输入小于选区：导出时从选区缩小到该帧，提示 `将缩至该帧`。
- 选区小于建议帧：不用建议帧去放大，改用选区实际像素，提示 `小于建议帧，不放大`。

不提供放大。不提供独立的「只缩放不裁」模式。

### 6.4 摆正

只为下刀前摆正，不单独成为模式。

- 「左转 90°」「右转 90°」。
- 微调 −15.0° 到 +15.0°，步长 0.1，默认 0。

旋转后的画布外是透明。裁剪框保持水平，坐标相对旋转后的外接矩形。改变 90° 时，未单独调整的选区按当前比例重新居中；微调不重置选区。

导出：

- 默认 PNG，透明保留。
- 沿用原格式且原格式为 JPG：透明处以墨色 `#080A0C` 填入，质量固定 95，提示 `JPG 将再编码`。
- 沿用 WebP：质量 90，保留透明。
- 沿用 AVIF：质量 60，保留透明。
- 沿用 GIF：保留 1 位透明，规则同转换。
- 沿用 PNG：仍是 PNG。

「无损 PNG」默认开启。关闭后文案：`沿用原格式。JPG 会再编码，质量 95。`

动画：同一选区用于每一帧，不拆成多张。GIF 源导出 GIF；动画 WebP 源导出动画 WebP；其余取合成后的当前逻辑（静图规则）。

SVG：不能直接按像素裁。铭文栏要求先填栅格宽度（默认与转换相同），按钮 `栅格化后裁剪`。未栅格化时不画出选区，开始处理会让该项失败，原因 `需先栅格化`。

### 6.5 成品

完成后「选区 / 成品」可切换。成品是选区像素，不是整图再压一遍。ZIP 与单项下载都给这份成品。

## 7. 边缘状态

| 状态 | 表现 |
| --- | --- |
| 空 | 置入区。文案：`置入图片` / `拖入、粘贴，或选择文件与文件夹` / 格式一行 / `处理在浏览器内完成。无账号，无水印，不上传。` |
| 拖入经过 | 水面起涟漪，刃线拉满。松手置入。拖出窗口则涟漪停 |
| 多种格式 | 队列照单全收。铭文栏按当前项显示控件，并提示参数按格式分别记住 |
| 失去透明 | 转换到 JPG 时舞台横条常驻，底色墨或白 |
| 动画 GIF | 队列标帧数。压缩保留帧。转换到 JPG、PNG 时横条 `将只保留首帧`。裁剪保持每帧同一刀口 |
| HEIC 解码受限 | 静图尝试用 libheif WASM 解码。动画 HEIC、不支持的位深、解码器缺失或解码抛错，一律失败，原因 `HEIC 解码受限`。不上传、不换服务器。舞台用失败板，不用破图图标 |
| HEIF | 与 HEIC 同一条解码路径，同一句失败原因 |
| JXL 无法压回 | 见第 4.3 节 |
| 失败 | 队列该项为失败色，写明原因。可重试。其余项不受影响 |
| 大图 | 软提示，不拦截。内存错误才失败 |
| 全部失败 | 可以打包的按钮保持禁用。摘要写 `0 张完成` |
| 部分失败 | 完成的可下载、可打包。提示失败项不进包 |
| 目标体积无效 | 该项失败，原因 `目标体积无效` |
| 文件损坏 | 解码失败，原因 `文件已损坏` |
| 编码器未载入 | 原因 `编码器未就绪` |
| 已取消 | 原因 `已取消` |
| 处理中 | 该项与舞台底边各有一条星轨。已知进度时银线填到百分比，并显示数字；PNG、GIF、SVG 可以只有星轨、没有百分比 |

失败原因只用这些句子，不写堆栈：

`文件已损坏`、`HEIC 解码受限`、`内存不足`、`已取消`、`编码器未就绪`、`暂不能压回原格式，请改用转换`、`需先栅格化`、`目标体积无效`。

## 8. 批量规则

- 一次运行，一种模式，一张接一张。
- 勾选了的排队项与失败项会跑；完成项不跑；「不处理」不跑。
- 压缩与转换的参数按格式共用。
- 裁剪的选区默认各管各的，模板来自当前比例与摆正。
- 文件夹递归。忽略的非图片只出现在一句提示里。
- 粘贴追加在队尾。
- 打包只收完成项，STORE 存储。
- 原文件一律不改写。
- 设备内存是唯一上限。

## 9. 文件命名

主文件名去掉原扩展名，记为 `{名}`。输出扩展名小写：`jpg`、`png`、`webp`、`avif`、`gif`、`svg`。`.jpeg` 与 `.jfif` 写出时用 `jpg`。

| 情形 | 文件名 |
| --- | --- |
| 压缩，按质量，JPEG / WebP / AVIF | `{名}.q{质量}.{扩展名}`，例 `塘莲.q85.jpg` |
| 压缩，PNG | `{名}.l{等级}.png`，例 `霜刃.l2.png` |
| 压缩，GIF | `{名}.g{等级}.gif`；有损不为 0 时加 `-y{有损}`，例 `动荷.g2-y30.gif` |
| 压缩，SVG | `{名}.min.svg` |
| 压缩，按体积 | `{名}.{目标}.{扩展名}`。目标 ≥ 1024 且能被 1024 整除时写成 `1MB`、`2MB`，否则 `100KB` 这种形式。例 `塘莲.200KB.jpg` |
| 转换 | `{名}.{新扩展名}` |
| 裁剪 | `{名}.{宽}x{高}.{扩展名}`，例 `霜刃.1080x1350.png` |
| 压缩包 | `纯钧-{模式}-{YYYYMMDD-HHmm}.zip`，时区 Asia/Shanghai。模式写 压缩、转换、裁剪 |

重名时在扩展名前插入 `-2`、`-3`：`塘莲.q85-2.jpg`。压缩包内扁平存放，不建子目录。

这些名字只用于下载。磁盘上的原文件保持原名。

## 10. 不做

- 滤镜、调色、曲线、胶片
- 水印、署名、贴纸
- 抠图、换背景
- 表情、像素画、拼图
- PDF、RAW、视频、多页 TIFF、BMP、ICO
- 独立的缩放工作室，以及裁剪之外的放大
- 镜像翻转
- 把 JXL、HEIC、HEIF 编回去
- 账号、登录、云同步、分享链接、服务端处理
- 多语言营销站、博客、更新日志、SEO 落地页
- 在界面上出现 Squoosh 或其他编码器产品的牌子
- 同一轮里让每张图使用不同的质量数字（裁剪选区除外）
- 色彩软打样。保留元数据时只原样留下 ICC，不另做色彩转换

编码器若某条 WASM 加载失败，可以在内部改走等价实现。用户仍只看到格式名与上面列出的编码器小字，不看到备用品牌。

## 11. 界面与动效

实现界面时遵守这些参数，不再换成另一套视觉。

### 11.1 材料

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| 墨 | `#080A0C` | 底 |
| 墨上 | `#101416` | 抬起的平面 |
| 塘水深 | `#071416` | 置入区下沿 |
| 塘水 | `#0C2427` | 水面 |
| 塘线 | `#1A3D40` | 发丝分割 |
| 水光 | `#245E63` | 水面高光，低透明度使用 |
| 刃银 | `#C8D0D4` | 正文、边线 |
| 刃亮 | `#EEF3F4` | 数字、当前项 |
| 刃哑 | `#7E8B90` | 次要说明 |
| 芙蓉 | `#F0E2D4` | 唯一点缀 |
| 失败 | `#B85A48` | 失败状态 |
| 完成 | `#8EA598` | 完成状态 |

芙蓉只用在三处：字标下的「去冗留华」、主按钮「开始处理」的左边 2px、星点里的一颗。不用它做大面积填充。

边角为直角。分割线 1px。不用磨砂玻璃，不用弥散阴影，不用渐变按钮。

字：

- 「纯钧」与短标题：Noto Serif SC，600。
- 界面汉字：Noto Sans SC，400 / 500。
- 数字、尺寸、质量、KB：IBM Plex Sans，等宽数字。

### 11.2 动效

动效是金属与水，时长固定，缓动 `cubic-bezier(0.16, 0.04, 0.12, 1)`，除非另注。

| 动作 | 时长 | 做法 |
| --- | --- | --- |
| 置入后工作室拉开 | 720ms | 舞台自左向右揭开，铭文栏自右向左，队列自下而上。用 clip-path，不弹跳 |
| 模式银线 | 480ms | 1px 线 scaleX 自 0 到 1 |
| 拖入经过 | 涟漪 1400ms，线性透明 | 指针处两圈细线涟漪向外淡出。置入区中线的刃从约 18% 拉到全宽，700ms。水面高光略抬亮 |
| 处理中 | 星点 2400ms 线性循环 | 1px 轨道上三颗 2px 星点匀速走过。有百分比时轨道填色，数字用 Plex |
| 对照分界 | 跟随指针，不补间 | 松开后一道冰色高光 180ms 淡出 |
| 主按钮悬停 | 160ms | 底色变为塘水，边线变亮 |

`prefers-reduced-motion: reduce` 时，上述过渡压到 1ms，星轨停止，控件仍可用。

### 11.3 控件状态

- 默认：1px 刃线边，透明底，刃银字。
- 悬停：底色塘水，边线变亮。
- 按下：底色 `#071416`。
- 当前：字为刃亮，边线为刃亮。
- 禁用：不透明度 0.32，没有悬停。
- 焦点：1px 芙蓉轮廓，偏移 3px。不用发光。
- 滑杆：轨道 1px；滑块是 2×14px 的竖刃，悬停时变为 2×18px。不用圆点。

主按钮「开始处理」左边 2px 为芙蓉，其余边为刃银。处理中该按钮文案改为「停止」。

## 12. 实现顺序（本阶段不做）

1. 工作室壳、队列、置入、命名与状态机，先用假字节跑通。
2. Worker 装入 MozJPEG、OxiPNG、libwebp、libavif、gifsicle、svgo。
3. HEIC/HEIF 用 libheif 解码，JXL 用解码器。失败统一走第 7 节的句子。
4. 按体积的二分改为真实字节。预览曲线可以保留为滑杆反馈。
5. 对照、裁剪框、摆正与像素帧钳制。
6. ZIP STORE、单项下载、元数据剔除。
7. 字体与 WASM 缓存，使第二次打开可离线。
